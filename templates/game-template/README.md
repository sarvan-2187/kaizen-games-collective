# Game template

1. Copy this folder to `games/<your-slug>/` (lowercase, dashes).
2. Replace `index.html` with your game. Keep it playable on phones if you can.
3. Edit `game.json` (the `slug` must match the folder name) and delete this README.
4. `npm run validate` then `npm run preview`.
5. Open a pull request. See CONTRIBUTING.md.
